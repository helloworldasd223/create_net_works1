# Create: NetWorks

Realistic Internet, Cellular Networks, Fiber Optics, Routers, PCs and Smartphones for **Create** & **Create: Power Grid**.

- Minecraft **1.21.1**
- **NeoForge** 21.1.200
- Requires Create 6.x, optional integration with Create: Power Grid

## Building

```bash
./gradlew build
```

The jar is produced at `build/libs/createnetworks-neoforge-1.21.1-1.0.0.jar`.

A prebuilt jar is also produced by the **Build Mod** GitHub Actions workflow
(`Actions` → `Build Mod` → latest run → `Artifacts` → `createnetworks-jar`).
